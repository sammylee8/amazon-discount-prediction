# Predicting Discount Depth on Amazon

## Requirements
Python 3.13.5 with the following packages:
- KModes
- Matplotlib
- NumPy 
- Pandas
- Seaborn 
- Scikit-learn
- SHAP
- Statsmodel
- XGBoost

## Data
The dataset used in this analysis is publicly available here:
https://github.com/octaprice/ecommerce-product-dataset/tree/main/data/amazon_com/best_sellers

Download the CSV, rename it to `amazon best sellers products.csv`, and place it 
in the same folder as the notebook before running.

## Usage
Run the .ipynb file in order from top to bottom.
